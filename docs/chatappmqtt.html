How to Chat:

  1. Open this page in multiple browser tabs or on different devices.
  2. All instances will automatically connect to the same chat room.
  3. Type your message in the input box and hit 'Send' or Enter.
  4. Your messages (and others') will appear in real-time in the chat log.
  5. **Important:** This uses a public test broker, so **do not send any sensitive or private information!**
