QR code appearance varies due to error correction levels (L, M, Q, H). Higher levels introduce more data redundancy, increasing density of black modules for greater resilience to damage. This is achieved using the Reed-Solomon error correction algorithm. Both QR codes encode the same URL, yet a QR with higher error correction can withstand scratches better, increasing its chance of being scanned, though there is some variation in the visual representation of the code. Thus the code that has greater error correction is said to be more "robust".
