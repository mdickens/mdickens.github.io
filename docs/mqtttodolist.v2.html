How to Use:

  1. **Get your List ID:** A unique ID is generated above.
  2. **Share:** Open this page in multiple browser tabs/devices, or share the URL with others. **Ensure everyone uses the SAME "To-Do List ID" for collaboration.** You can manually change the `TODO_LIST_ID` in the JavaScript if you want a fixed room.
  3. **Add Tasks:** Type into the input and click "Add Task."
  4. **Manage Tasks:** Check the box to mark complete, click 'X' to delete.
  5. **Real-time:** All changes will instantly reflect across all connected clients for that List ID.
  6. **Important:** This uses a public test broker, so **do not add sensitive information!**
