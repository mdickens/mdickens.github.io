How to Play:

  1. Open this page in multiple browser tabs or on different devices.
  2. Each instance will get the same unique "Drawing ID".
  3. Draw on the canvas! Your strokes will appear on everyone else's canvas in real-time.
  4. Change the brush color and thickness using the controls.
  5. Click "Clear Canvas" to clear everyone's canvas.
  6. **Important:** This uses a public test broker, so **do not draw anything sensitive!**
